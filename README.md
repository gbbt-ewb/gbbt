# 🌈 GBBT Banking

GBBT Banking is a creative and inclusive mobile banking application designed to provide users with a fun, vibrant, and engaging financial management experience. The application combines traditional banking features with unique personalized tools and community-driven experiences.

## 📱 Project Overview

GBBT Banking is a modern mobile banking platform that offers users a colorful and user-friendly interface for managing finances. The application provides banking essentials such as transfers, savings, investments, and bills payment, alongside innovative lifestyle-oriented financial features.

### ✨ Key Features

#### 💸 Bank Transfer
- Instant money transfers
- Fast and secure transactions

#### 💰 Save
- Savings management tools
- Financial progress monitoring

#### 📈 Invest
- Investment tracking and opportunities
- Wealth growth insights

#### 🧾 Bills Payment
- Convenient bill payment services
- Simplified transaction management

#### 🤖 AI Chatbot
- AI-powered financial assistant
- User support and guidance

#### 💖 Money Match
- Personalized financial compatibility feature

#### ✨ Vibe Check
- Financial wellness assessment
- Savings habit evaluation

#### 🗺️ BrokeFinder
- Wealth and financial location mapping

#### 📊 Aura Exchange
- Investment and financial trend visualization
